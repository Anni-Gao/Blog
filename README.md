## 📌 Overview

This repository contains the **Code scripts** and **Visualization code** behind my blog posts

The codebase is organized by topic and post, seamlessly mapping to the Markdown articles on my blog. Each module is self-contained, producing high-quality visuals and handling content logic for specific posts.

---

## 📂 Contents

- 🎨 **Visualizations (`figures.py`)**: Matplotlib scripts for generating diagrams and illustrations (math, robotics, algorithms, and more) featured in the blog.
- 🐍 **Content Scripts (`content_blog.py`)**: Helper scripts and code snippets for my blog contents.

---

## 🗂 Structure

The project mirrors the structure of the blog posts for easy navigation:

```text
blog-codes/
├── robotics/
│   └── fundamental/
│       └── 01/                 # Corresponds to "Robotics Blog Series · Robot Fundamentals · Post #1"
│           ├── images/         # Generated figures for this post
│           ├── content_blog.py # Code snippets for this post
│           └── figures.py      # Visualizations (matplotlib)
├── ...
└── README.md
```

💡 Note: Each numbered folder directly maps to the corresponding post on the blog. For example, see the post **[Robotics Blog Series · Robot Fundamentals · Post #1](https://anni-gao.github.io/posts/robotics_fundamental_01_linear_algebra/)**.
